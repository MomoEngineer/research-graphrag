#
# Eine Kennung je Zeile – DOI oder arXiv-ID. Erzeugt wird daraus je Kennung eine Stub-Datei
# `*.refjson` in diesem Ordner:
#
#     python -m scripts.resolve_references --dry-run
#     python -m scripts.resolve_references
#
# `#` leitet einen Kommentar ein, auch hinter einer Kennung. Erledigte Einträge dürfen stehen
# bleiben: Vor jeder Abfrage wird gegen Korpus, vorhandene Stub-Dateien und `_duplikate/`
# geprüft. Diese Datei wird vom Lauf nur gelesen, nie verändert.

#   10.1145/3696410.3714748          doi:10.1145/…          https://doi.org/10.1145/…

#   cs/0501001                       10.48550/arXiv.2404.16130
